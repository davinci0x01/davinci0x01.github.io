ازاي تعمل مقلب في صاحبك إنك هكرته

ارفع صفحة بسيطة على GitHub Pages في دقايق وابعت الرابط لصاحبك — شرح خطوة بخطوة مع الكود.

Jan 29, 20262 min readby 0xDaVinci

مقدمة

في الشرح ده هتتعلم خطوة بخطوة إزاي ترفع صفحة على الإنترنت مجانًا باستخدام GitHub Pages، وتبعت الرابط لصاحبك يفتحه… ويتفاجئ برسالة إنه اتهكر.

الفكرة

المقلب كله مجرد صفحة HTML بتظهر رسالة alert — مفيش أي اختراق حقيقي ولا أي ضرر على جهاز صاحبك.

خطوات رفع الموقع على GitHub Pages

  1. سجّل الدخول إلى GitHub: ادخل على github.com وسجّل الدخول أو اعمل حساب جديد لو معندكش.
  2. أنشئ مستودع (Repository) جديد: اضغط على زر New، اختار اسم للمستودع (مثلاً my-website)، خليه Public، وبعدين اضغط Create repository.
  3. ارفع ملفات موقعك: تقدر ترفعها يدويًا من زر Upload files أو باستخدام Git من جهازك.
  4. فعّل GitHub Pages: من صفحة المستودع ادخل على Settings ← Pages، واختار الفرع main والمجلد / (root) واضغط Save.
  5. هيظهر لك رابط موقعك بعد ثواني في نفس الصفحة، غالبًا بالشكل ده: https://YOUR-USERNAME.github.io/REPO-NAME/

  • تقدر تعدل الكود أو تضيف صفحات جديدة براحتك.
Tip

أول نشر ممكن ياخد دقيقة أو اتنين لحد ما الرابط يشتغل — لو لقيت صفحة 404 استنى شوية واعمل Refresh.
